# Threerace Sports

Site institucional da Threerace Sports, com páginas dos eventos realizados no
Brasil e no Uruguai.

## Desenvolvimento

Requisitos:

- Node.js 22 ou superior
- npm

Comandos:

```bash
npm install
npm run dev
```

## Produção

O projeto utiliza Next.js e está preparado para publicação automática na
Vercel a partir da branch `legendsbikerace`.

```bash
npm run build
npm run start
```
